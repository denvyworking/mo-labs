# Лабораторные работы по курсу «Теория многоагентных систем»

Многоагентная система городской доставки заказов автономными курьерами-роботами с общей ограниченной
зарядной инфраструктурой. Python 3.11+, зависимости: `matplotlib` (графики), `python-docx` (отчёты).

| Работа | Папка | Отчёт |
|---|---|---|
| ЛР1. Спецификация и архитектурное проектирование МАС | [lab1](lab1) | [report.docx](lab1/report.docx) |
| ЛР2. Исследование механизмов распределения задач и координации | [lab2](lab2) | [report.docx](lab2/report.docx) |
| ЛР3. Проектирование механизма переговоров и разрешения конфликтов | [lab3](lab3) | [report.docx](lab3/report.docx) |
| ЛР4. Диверсионный анализ и оценка надёжности МАС | [lab4](lab4) | [report.docx](lab4/report.docx) |

Ядро системы — `lab1/mas`, механизмы ЛР2–ЛР4 подключаются к нему как режимы.

```
python lab1/web/server.py      # веб-демонстрация всех режимов: http://localhost:8000
python lab1/run.py --list      # режимы в командной строке
python lab2/experiments.py     # эксперименты ЛР2 (аналогично lab3, lab4)
```
